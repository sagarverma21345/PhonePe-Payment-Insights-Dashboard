# 📊 PhonePe Payment Insights Dashboard

A Power BI dashboard built to analyze PhonePe payment transactions and provide meaningful business insights through interactive visualizations. The project demonstrates the complete analytics workflow—from data transformation and cleaning to data modeling, DAX measures, and dashboard design.



## 🚀 Project Overview

The objective of this project is to analyze PhonePe payment transaction data and create an interactive dashboard that helps users understand transaction performance, payment success rates, user demographics, service usage, and monthly trends.

The dashboard was built using **Power BI** and includes interactive features like **hover effects**, slicers, and dynamic visualizations for a better user experience.



## 🛠️ Project Workflow

### 1. Data Collection
- Imported transaction dataset into Power BI.

### 2. Data Transformation (Power Query)
Performed data cleaning and transformation including:

- Removed duplicate records
- Handled missing/null values
- Corrected data types
- Renamed columns
- Removed unnecessary columns
- Standardized data for analysis

---

### 3. Data Modeling
- Created relationships between tables
- Built a Date Table for time-based analysis
- Optimized the data model

## 📈 Business Insights

Some key insights generated from the dashboard:

- Overall payment success rate reached **95.93%**.
- Total transaction value exceeded **3.47 Billion**.
- More than **300K transactions** were processed.
- Gold Loan, Mutual Fund, Bike Loan, and Credit Score services contributed significantly to transaction value.
- Weekend transactions accounted for nearly **72%** of total transactions.
- Monthly transaction trends helped identify peak activity periods.
- Payment status analysis highlighted failed, pending, and successful transactions for operational monitoring.
